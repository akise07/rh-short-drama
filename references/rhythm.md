# 节奏规范（RH 短剧通用）

> 切分镜前通读。产出为 `EP##/剧本分镜.md`。

---

## 核心原则

**不卡固定时长，按事件密度切分。** 一集讲完一件事就收，30 秒也行，90 秒也行。
**钩子不断比时长整齐重要。**

---

## 🔴 先定单集切点：用台词量反推

**一集的容量由台词量决定，不由剧情自然段落决定。** 凭感觉切，必错。

```text
① 脚本抽出候选区间全部直接引语，按「含标点字数 ÷ 4.5」算台词总时长
② 允许的单集总时长 ≤ 台词总时长 ÷ 0.55（R7a 反推）
③ 若算出超过 90 秒上限 → 砍掉尾部剧情，把切点前移
④ 在候选切点附近比较：台词稀疏处 = 好切点；台词密集区 = 坏切点
```

> **踩坑实录**：某项目原文 197 行处有个读起来很自然的剧情断点，凭感觉切在那里。
> 一算台词 **78.9 秒**，90 秒单集只剩 11 秒画面，第一集连开场都铺不开。
> 前移到 149 行（台词 52.7 秒 / 单集 78 秒 / 占比 67.7%）才站得住。
>
> **教训**：**自然段落 ≠ 可切点**。切完必须回算台词量，算不过就前移，别硬撑。

**红线**：不许为了留住剧情而压缩台词；也不许为了凑集数而增写台词。
切点冲突时，**砍剧情、不砍台词**。

## 分镜层级：大分镜 + 小分镜（强制）

| 层级 | 时长区间 | 对应 |
|---|---|---|
| **大分镜** | **4-15 秒** | **一个视频生成单元**（U01/U02…） |
| **小分镜** | 1.5-6 秒 | 提示词里的秒级段落 |

```text
一个大分镜 = 一次提交 = 一个 提示词.md 单元
```

**编号**：大分镜 `B01/B02…`（**连续，无半编号**），小分镜 `S01/S02…`（全片连续）。
时间码全片相对计时；大分镜区间 = 内部小分镜区间的并集；各级首尾相接。

### 🔴 超 15 秒必须拆

**不是「拆成多个生成单元」，是「拆成多个大分镜」**，拆开后各自编号、各自计时、
各对应一个生成单元。

| 项 | 规则 |
|---|---|
| 大分镜时长 | **4-15 秒**，硬上限 15 秒 |
| 超限处理 | 拆成两个（或更多）独立大分镜 |
| 编号 | 全片连续（B01、B02…），**不出现 B05a/B05b** |
| 拆分点 | 优先**句子边界**（按台词分配），其次动作完成瞬间、场景转换 |

> **为什么**：大分镜既是叙事单位也是生成单位，超 15 秒服务端可能截断或生成失败。
> **宁可拆开，不可压缩台词。**
>
> **教训**：曾把一个 74 字台词段撑到 21.5 秒来装台词，
> 等于把「台词说不完」换成「视频生不出来」。拆成 10.0s + 11.5s 后两头合规。

## 硬性指标

> 🔴 **画幅决定档位**：**16:9 横屏为默认档**（用户 2026-09-20 定），下表给两档对照。
> 横屏观众是主动播放、容错更高，故节奏可放宽；9:16 竖屏是滑刷场景，取收紧档。

| 项目 | 16:9（默认） | 9:16（收紧档） |
|---|---|---|
| 大分镜时长 | **4-15 秒**（6-14 秒为优秀区间） | 同左 |
| **超 15 秒 → 拆成独立大分镜** | **必须** | **必须** |
| 无台词大分镜 | **10 秒** | **8 秒** |
| 前 3 秒 | 5 秒内出现冲突/异常；开场环境镜允许 1 个，**必须承载信息**（时间/地点/身份） | **前 3 秒**必须出现冲突/异常，禁环境空镜 |
| 单镜时长 | 无台词镜 3-4 秒；情绪镜可到 6 秒 | 无台词镜 ≤2.5 秒；情绪镜 4-5 秒 |
| 小分镜数 | 约 24 镜/集（90 秒档的**参考值**，按事件密度浮动） | 同左 |
| 小分镜时长 | **1.5-6 秒**（6 秒是上限，不是定值） | 同左 |
| 单集时长 | **≤90 秒**（**可显式放宽到 120 秒**，须在项目规范声明） | **≤90 秒** |
| 台词字数 | **不改原文**（照抄） | 同左 |

> **不变项（两档通用）**：大分镜 4-15 秒硬上限、每个大分镜必须推动剧情、
> 台词占比 ≥55%、无台词镜的铺垫/长镜头豁免（R6a / §四）。

**两个必改项**：① 开场即冲突（禁地理介绍/氛围铺垫/字幕交代/环境空镜）② 闪回砍到骨

## 🔴 台词与表演四铁律

> **2026-09-17 修订**：原「台词不可动」放开为「改编授权」，
> 并新增「节奏不可拖沓」「情绪要够足」两条。

### 一：台词为主，砍无台词剧情（替代原「台词不可动」）

**让对话占据成片大部分，手段是砍掉不说话的剧情，不是改台词、也不是堆新台词。**

| 项 | 规则 |
|---|---|
| **现有台词** | **不改**，保留原文，措辞基本不动 |
| **主要手段** | **压缩 / 删除无台词的剧情段**，让对话的时长占比自然上升 |
| **改编目的** | 让对话更符合视频逻辑、更自然（调整顺序、补衔接词）；**很多时候不需要改** |
| **可选增写** | 仅在对话衔接生硬或逻辑断裂时补极少量台词，**不作为主要手段** |
| **禁止** | 删除原文信息、改变人物设定或立场、凭空发明剧情事件 |

> **达成路径（按优先级）**
>
> | 优先级 | 手段 |
> |---|---|
> | 1 | **删无台词段**，去掉不推动剧情的空镜、过场、氛围镜（**首选**） |
> | 2 | **压缩无台词段时长**，单镜压到 1-2.5 秒 |
> | 3 | **合并信息**，用一句话或一个镜头带过原本一段画面 |

> **历史教训的适用范围**：初版曾给主角编大量**画外音**（占台词 70%），节奏被拖死。
> 那是**叙述性画外音**的问题，纯叙述性画外音仍尽量少用。

原文非台词内容的处理：

| 原文内容 | ❌ 错误 | ✅ 正确 |
|---|---|---|
| 地理/环境描写 | 写成旁白 | 画面呈现，或直接删 |
| 心理描写 | 写成内心独白 | **转成表演动作** |
| 叙述性说明 | 写成解释性画外音 | **转成视觉符号** |
| 直接引语 | — | **保留**（可微调，不删） |

**示例**（父亲的心理戏）：

- 原文：`很想告诉他，那都是传说而已…可在看到儿子眼中的希冀，刚到嘴边的话咽了回去。`
- ❌ 写成叙述性画外音念出来（约 40 字）
- ✅ **四段表演**：张嘴 → 喉咙动 → 话咽回 → 目光移开
- ✅ 也可由别的角色补一句对话，把这层意思**用对话带出来**

### 二：台词字数口径 = 含标点

```text
台词时长 = 含标点字数 ÷ 4.5
```

**标点代表停顿，停顿也占时间。** 用纯汉字口径会低估（实测差 4.2 秒/百字）。

**统计必须用脚本**（`len(台词)`），不凭感觉标。
曾发现台词表标 40/34/12，实际是 36/33/13。

### 三：台词占比 ≥55%

```text
台词占比 = 台词总时长 ÷ 单集总时长       目标 ≥ 55%
```

| 占比 | 判定 |
|---|---|
| ≥ 60% | 优秀，对话驱动 |
| 55-60% | 合格 |
| 40-55% | 偏弱，**砍无台词段** |
| < 40% | ❌ 不合格，变成画面展示，不是短剧 |

**反推公式**

```text
允许的单集总时长 ≤ 台词总时长 ÷ 0.55
```

> **台词量由原文决定、不增不减。** 占比靠**压缩无台词剧情**达成。
> 台词量不变，把总时长压下来，占比自然上升。
> **不靠增写台词堆占比。**
>
> 占比目标**不豁免 15 秒拆分规则**。

### 四：无台词段落加速

没有对话的地方一律加快，把时长**让给对话**。

| 大分镜类型 | 时长策略 |
|---|---|
| **无台词** | 压到 **4-10 秒（16:9 默认档）/ 4-8 秒（9:16 收紧档）**；单镜按画幅档（见「硬性指标」） |
| **有台词** | 给足：含标点字数 ÷ 4.5 + 表演时间 |

推导：① 算全集台词总时长 → ② 补足到占比目标 → ③ 剩余给无台词段逼出快切 →
④ 无台词段超**本档上限**（16:9 → 10 秒 / 9:16 → 8 秒）继续删镜

> **关键认知**：**无台词段落是唯一的压缩空间**，对话是主要的内容载体。

#### 例外：铺垫镜与长镜头（可豁免本档上限）

**4-10 秒是默认档，不是铁律。** 两类特殊无台词镜可以突破，甚至**应该**突破：

| 类型 | 何时用 | 时长 | 硬要求 |
|---|---|---|---|
| **铺垫镜** | 给后续爆点蓄势，需一次把**人物状态 / 空间关系 / 悬念**铺足 | 8-12 秒 | **步步推进**：信息在变、情绪在涨，不是静态铺陈 |
| **长镜头** | 一镜到底的调度/运镜**本身就是看点**（"爆款长镜头"） | 8-15 秒 | **运镜有起承转合**，表演与画面同步推进 |

**边界（防豁免被滥用）**

- 必须在分镜表里**显式标注** `[豁免:铺垫]` / `[豁免:长镜]`，**不标注一律按当前画幅档的上限卡**（16:9 → 10 秒 / 9:16 → 8 秒）；
- 仍受**大分镜 15 秒硬上限**（R5）约束。那是服务端技术限制，超了会被截断，**不是节奏偏好**；
- 每集建议 **≤2 个**、累计豁免时长 ≤单集 **20%**；若一集里超过一半时间是无台词长镜，那就是画面展示、不是短剧（R7a 台词占比 ≥55% 仍要成立）；
- **豁免只放松时长**：该镜仍须推动剧情或堆情绪，「不允许纯过场」不变；镜内必须有变化（运镜推进 / 表演层次 / 光影与声音推进），**静止凝视不算长镜头**。

#### 整活镜（Q 版插播）的节奏约束

**仅当开工第 4 问启用了 Q 版整活时才适用**（见 R37 / `styles/chibi-gag.md`）。

| 项 | 约束 |
|---|---|
| 单镜时长 | **4-6 秒**（**独立大分镜**，受 R5 的 4-15 秒区间约束，不能短于 4 秒） |
| 每集数量 | 建议 **≤3 个** |
| 累计时长 | ≤单集 **20%**（项目规范可覆盖） |
| **禁止连排** | **不许两个整活镜连着**，中间至少隔一个主画风大分镜 |
| 位置 | 优先插在**信息密集段之后**，或**风险镜原位**；**不许打断高潮** |
| 计入 | 整活镜多半无台词，**计入无台词段**，仍受 R7a 台词占比 ≥55% 约束 |

**两类整活镜的时长算法不同，别混**：

| 类型 | 时长从哪来 |
|---|---|
| `[整活:风险]` | **原位替换**：占用原风险镜那一拍的时间，**不额外增加单集时长** |
| `[整活:科普]` / `[整活:心理]` | **插播**：新增时长，从无台词预算里出，**会挤压别处**，所以要控量 |

## 🔴 节奏不可拖沓（2026-09-17 新增）

**短剧的命是节奏。宁可信息过载，不可让观众等。**

> ⚠️ **本节纪律的松紧随画幅变**（见下），但**「每个大分镜必须推动剧情」「台词占比 ≥55%」两条不变**。

### 横屏 16:9（🔴 **默认档**，用户 2026-09-20 定）

横屏接近番剧/影视剧的观看场景，观众是**主动选择播放**，不是被动刷到，**容错更高**。

| 手段 | 做法 |
|---|---|
| 前 3 秒 | **仍要尽快入戏**：5 秒内必须出现冲突/异常；开场环境镜允许 1 个，**必须承载信息**（时间/地点/身份），不能是纯氛围 |
| 无台词段 | 压到 4-10 秒；单镜 3-4 秒（**铺垫镜与长镜头豁免**，见 §四） |
| 单镜时长 | 无台词镜可到 **3-4 秒**；情绪镜可到 6 秒（豁免镜不设此限，见 §四） |
| 无台词大分镜 | 上限 **10 秒**（本该按 §四 豁免的更可放开，仍 ≤15 秒） |
| 单集时长 | 基准 **≤90 秒**；可显式放宽到 **120 秒**（须在项目规范声明） |
| 禁止 | 「凝视空镜」「环境交代」「走路过程」这类无信息量的长时间镜头 |
| 每个大分镜 | 必须推动剧情或揭示信息，**不允许纯过场** |

### 竖屏 9:16（**改画幅时适用**，取收紧档）

竖屏看剧是**滑动场景**，观众的手指随时准备划走，容错极低，所以整档收紧。

| 手段 | 收紧到什么程度 |
|---|---|
| 前 3 秒 | **必须**在 3 秒内出现冲突/异常/对话；**禁止**地理介绍、氛围空镜、字幕交代 |
| 无台词段 | 压到 4-8 秒，单镜 1-2.5 秒快切（**铺垫镜与长镜头豁免**，见 §四） |
| 单镜时长 | 无台词镜 ≤2.5 秒；情绪镜可到 4-5 秒但要有表演变化（豁免镜不设此限） |
| 无台词大分镜 | 上限 **8 秒** |
| 单集时长 | **≤90 秒** |
| **不变** | 每个大分镜必须推动剧情；台词占比 ≥55%；大分镜 4-15 秒硬上限 |

> **判定方法**：逐镜问「这一镜去掉，观众会不会看不懂？」答案是「不会」→ 删。

> 🔴 **两条上限写在 SKILL 红线 R6 里**（无台词大分镜、单集时长）。上表是**按画幅分档**的正式口径；
> 要在本档之外再放宽，**必须在项目规范里显式声明覆盖**，不要默默违反。

## 🔴 人物情绪要够足（2026-09-17 新增）

**表演不能温吞。** 每段都要有明确的情绪强度与变化。

| 要求 | 做法 |
|---|---|
| 情绪有**起点与终点** | 每段标注「从 X 到 Y」（压抑→松动 / 好奇→失望 / 麻木→刺痛） |
| 心理**外化**成动作 | 手指蜷起、喉结动、呼吸变浅、目光下移、肩膀垮下 |
| 强度**写进提示词** | 明确写「表演给足」「情绪饱满」「不可温吞」 |
| 关键情绪点**给时间** | 情绪转折处可给 2-4 秒特写，让表演被看见 |
| 禁止 | 全程一个表情、只有台词没有反应镜、情绪无落差 |

> **反例**：父亲听到儿子说「神会保佑我们」，只是「看了一眼」→ 太平。
> **正例**：张嘴要否定 → 喉咙动了一下 → 把话咽回去 → 目光从儿子脸上移开 →
> 肩膀微微塌下去。**四段表演，情绪可见。**

## 压缩手段优先级

删冗余镜 → 压缩单镜时长 → 叙述转画面 → 心理转表演 → 信息前置 → 闪回压缩 → 符号化

| 手段 | 示例 |
|---|---|
| 删重复镜 | 5 镜压到 3 镜，去掉信息重复的 |
| 叙述转画面 | 「村中见不到老人」→ 一个空村道镜头 |
| 心理转表演 | 内心独白 → 四段面部表演 |
| 符号化 | 死因用「一条手臂在水中垂下」一个镜头带过 |

## 单镜时长分配参考

| 镜头类型 | 时长 | 说明 |
|---|---|---|
| 强冲突/动作 | 2-3 秒 | 快切，不给喘息 |
| 信息交代 | 3-4 秒 | 观众需读完面板/看明白 |
| 情绪落点 | 4-5 秒 | 表演需要时间 |
| 氛围凝视 | 5-6 秒 | **上限，超了必砍** |
| 定格收尾 | 3-5 秒 | 段末钩子，别拖 |
