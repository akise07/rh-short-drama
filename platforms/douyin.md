## 1. 画幅与时长档

| 项      | 值                    | 级别 |
| ------ | -------------------- | -- |
| 画幅     | **16：9 竖屏**（本平台场景要求） | 🟢 |
| 单集时长下限 | **≥30 秒**（低于判质量问题）   | 🟢 |
| 极速档    | \~90 秒（中段 40-50 秒）   | 🟡 |
| 主流档    | 2-3 分钟（中段 60-90 秒）   | 🟡 |
| 完整版档   | \~5 分钟（中段 2-3 分钟）    | 🟡 |

> 🔴 **画幅冲突警示**：本技能**默认画幅是 16:9 横屏**（用户 2026-09-20 定），连带三件事：
> ① **关键帧与场景图**尺寸改 `1536x1024`（**角色四视图不用改**，它固定 16:9、与画幅无关）；② **节奏换 16:9 收紧档**（见 `rhythm.md`）。

> **本链路默认走极速档**（单集 ≤90 秒，与 R6 一致）。要切主流档需同时重算
> R7a 的台词占比反推与切集点。**不要一集跨两档。**

## 2. 节律档（滑刷场景，容错最低）

| 秒位     | 要求                           | 级别 |
| ------ | ---------------------------- | -- |
| 0-3    | 开场钩，**零铺垫**（禁地理介绍/氛围空镜/自述身世） | 🟡 |
| 3-10   | 交代核心矛盾 + 人物关系 + 主角目标         | 🟡 |
| \~30   | **首次反转／爽点必须出现**              | 🟡 |
| 全程     | 每 **20-30 秒**一处情绪节点          | 🟡 |
| 末 5-10 | 结尾强钩，力度大于全集冲突，留白/黑屏收尾        | 🟡 |
| 禁止     | 开场铺垫 >10 秒；连续单向施压 >30 秒无反击   | 🟡 |

> **滑刷属性决定一切**：观众手指随时准备划走，容错远低于横屏平台。
> 本平台的节律档取**最严档**，比 `rhythm.md` 的竖屏口径更紧（尤其"每 20-30 秒一个节点"）。

## 3. 标题与封面

### 3.1 标题

公式与槽位见 `references/viral.md` §5.1。本平台约束：

| 项       | 值                            | 级别 |
| ------- | ---------------------------- | -- |
| 字数      | 短，宁短勿长（一屏读完）                 | 🟡 |
| 标点      | 可用冒号/问号制造停顿，**少用句号**         | 🟡 |
| 禁用营销词   | 「热播」「爆款」「强推」等                | 🟢 |
| 禁用极端引流词 | 「灭门」「逆天改命」「疯批绝杀」「绿帽」「极致复仇」等  | 🟢 |
| 禁用绝对化词  | 「全网最火」「必看封神」等                | 🟢 |
| 禁止      | 煽动性别/地域/婚恋对立，绑定社会恶性事件或灾难热点引流 | 🟢 |

> 🔴 **标题、封面、简介、正文是四链路联合审核**：正文合规而标题踩词，照样驳回。

### 3.2 封面

| 要求        | 说明                              | 级别 |
| --------- | ------------------------------- | -- |
| 复用关键帧 S01 | 不单独出图，避免风格漂移（见 `viral.md` §5.2） | 🟡 |
| 必须有       | 人脸 + 明确表情 + 冲突元素                | 🟡 |
| 禁止        | 营销字样、视觉擦边、**主体五官缺失**、文字叠印       | 🟢 |
| 尺度一致      | 封面尺度必须与正文一致，禁"封面猎奇、正文保守"        | 🟢 |

## 4. 审核尺度

**适用法规侧红线见** **`viral.md`** **§7**（含备案分层、AI 标注、创作红线全表）。本平台追加：

| 项           | 要求                                                          | 级别 |
| ----------- | ----------------------------------------------------------- | -- |
| 备案          | 先备案后上线；三类低成本短剧由平台审核并统一编号上报                                  | 🟢 |
| **AI 内容标注** | AI 占比 >50% → **片头前 3 秒 + 封面 + 简介**三处标注（另有"前 5 秒"口径，取严用 3 秒） | 🟢 |
| 版权          | 改编须书面授权（含 AIGC 改编与分发范围）；AI 洗稿网文同样判侵权                        | 🟢 |
| 成片质量        | 机械配音、人物穿模、音画不同步、卡顿、乱字幕、烂尾断更 → 判劣质拒审                         | 🟢 |
| 画面          | 禁流血/伤口特写、禁刀具细节、禁慢镜放大击打、禁擦边贴身、禁暗黑惊悚滤镜、禁抽烟酗酒特写                | 🟢 |

> **价值观侧最易翻车的三条（2026 收紧）**：私刑复仇／以暴制暴、拜金炫富、家庭婚恋对立。
> 爽剧套路在这三条上直接失效，**改写比硬扛划算**。

## 5. 音频口径（已定案）

| 项        | 值                             | 级别    |
| -------- | ----------------------------- | ----- |
| **生成侧**  | **永不配乐**，只留音效（R11a）           | 🟢 定案 |
| **BGM**  | **由用户后期自行添加**，不属本链路职责         | 🟢 定案 |
| **音效写法** | 给后期 BGM 留空间：断续点状、低频克制、中高频让给台词 | 🟢 定案 |

> **2026-09-20 用户拍板**：生成链路不加 BGM，用户后期自己配。
> 因此平台侧"带 BGM 更利于推荐"的习惯**不由本链路处理**，也不构成对 R11a 的例外。
>
> 🔴 **但有一条连带要求**：因为后期要在音效轨上叠 BGM，音效**不要满铺**（不要全 layer 堆叠、
> 不要占满低频）。糊了**后期无法补救**，音效已烧进轨里。详见 `prompt-format.md` §4 声音设计。
