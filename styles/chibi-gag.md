# 风格：Q版整活（叠加画风）

> 🔴 **这是一套"叠加画风"，不是主画风。**
> `role: overlay` 的含义：它**与主画风共存**，用来插播整活镜，**不替代**主画风。
> 开工时先选主画风（`role: main` 的那批），**再单独问是否启用本风格**。

## 1. 一句话定位

**主线是正剧，整活镜是"旁白式的可视化解说"。**
同一个角色、同一套渲染管线，**只把比例和细节降级**，所以切进来不违和、切出去不破戏。

> **不违和的关键**：渲染路线**必须与主画风同源**（同一套 CG 渲染管线），
> 只改比例、简化细节。**不要做成 2D 平涂或日漫风**，那样一插进来就像两个片子拼的。

## 2. 风格特征（与主画风逐维对照）

| # | 维度 | 主画风（示例：`guoman-3dcg`） | **本风格（Q版整活）** |
|---|---|---|---|
| 1 | 渲染路线 | 偏写实的 CG 电影渲染 | **同源 CG 管线，但比例 Q 化、细节降级** |
| 2 | 比例 | 写实人体比例 | **头身比约 1:2**（头极大、身短），四肢短粗，手脚简化为圆钝块 |
| 3 | 五官 | 美术化精致、虹膜略大于真人 | **眼占脸 1/3 以上**，鼻简化成点或小三角，嘴用夸张形变（大开口 / 波浪线 / 一字） |
| 4 | 皮肤 | 次表面散射、无毛孔 | 光滑哑光、**无任何纹理**（更简化，不是更写实） |
| 5 | 毛发 | 一束束三维建模块面 | **保留主画风的发色与轮廓辨识度**，简化成整块 + 分块刘海，**不做一束束** |
| 6 | 服装 | 织物克重、受力褶皱 | **保留主画风的配色与标志性配饰**（用来认人），细节简化，不做褶皱物理 |
| 7 | 光照 | 柔和三点 + 轮廓光、明暗交界 | **柔和平光 + 极轻轮廓光**，不追求电影感层次 |
| 8 | 色调 | 暖金 × 青灰，区间压窄 | **同色系，饱和度略提**（整活感），但**不许跳出全片色调** |
| 9 | 运动 | 写实受力、物理可信 | **弹性夸张**（squash & stretch），位移可不像物理，**但不画速度线** |
| 10 | 画面文字 | 无叠印 | **同样无叠印**（见下） |

### 🔴 两条硬纪律

**① 身份识别特征必须与主线一致。** 发色、瞳色、服饰配色、标志性配饰，是观众"认出这是谁"的依据。
Q 版可以改比例，**不能改这几项**。改了就不是"整活"，是换了个角色。

**② 画面内不生成文字。** 科普、字面梗**一律用图像表意**（物件 / 气泡 / 箭头 / 图标），
文字交给后期字幕层。理由：一是与全片"无文字叠印"的纪律一致，二是模型生成中文必糊。

```text
负面：不要写实人体比例（不要细长四肢、不要正常头身比）；不要 2D 平涂、赛璐璐、线稿勾边、

```

## 5. 与主画风的关系（🔴 共存规则）

| 项 | 规则 |
|---|---|
| **共存** | 二者**并存**，整活镜是插播，**不替换**主画风 |
| **不混串** | 🔴 **一个生成单元只能用一套风格串**。整活镜**必须独立成大分镜 / 生成单元**，绝不与主画风镜头混在同一单元里 |
| **不混图** | 整活镜只投喂 **Q版参考图**；主画风镜头只投喂主画风参考图（R27a） |
| **切点** | 单元之间是**硬切**，不要写"风格渐变/过渡" |
| **资产** | Q 版四视图**单独出**，从主画风基准件**参照**派生（见 `character-consistency.md`） |

> **为什么必须独立成单元**：技能铁律是「一条提示词一套风格层」「风格层与投喂参考图必须同风格」。
> 把 Q 版和写实塞进同一个提示词，模型只会给你一个四不像，而且投喂图必然冲突。

## 6. 三种用法（启用后按此判定）

| 类型 | 用在哪 | 标注 | 说明 |
|---|---|---|---|
| **科普整活** | 交代世界观 / 规则 / 设定背景 | `[整活:科普]` | 正剧里讲这些会拖节奏，用 Q 版图示一带而过 |
| **风险规避** | **画面尺度类风险镜头**（血腥、伤害、危险动作、武器、挑衅性肢体冲突） | `[整活:风险]` | 用 Q 版小人 + **字面梗**替代。**必须写明替代了什么** |
| **心理整活** | 搞笑向的心理活动 / 吐槽 / 情绪外化 | `[整活:心理]` | 替代"内心独白"的一种合法出路 |

### 6.1 字面梗的写法（`[整活:风险]` 的核心手法）

**把危险内容谐音化 / 字面化成一个无害物件，放进联想气泡。**

> **范例（首例实战样本，非通用标准）**
> 原内容：`吃紫蛋`（「吃子弹」的谐音，属风险镜头）
> 处理：`[整活:风险]` 替代「吃子弹」
> 画面：Q版小人闭眼认命 → 头顶弹出联想气泡 → 气泡里是**一颗紫色蛋** → 小人把蛋吃下
> **要点**：气泡里必须是**字面物件**（紫蛋就是一颗蛋），不是子弹、不是血、不是任何武器。
> **梗的落点靠"形"，不靠字幕解释。**

### 6.2 🔴 不能靠 Q 版规避的红线（重要）

整活镜只处理**画面尺度**类风险。**价值观类一票否决项不能靠 Q 版包装**：

| 红线类型 | 能不能用整活镜处理 |
|---|---|
| 流血 / 伤口 / 刀具特写 / 危险动作 | ✅ **可以**（这正是它的主要用途） |
| 私刑复仇 / 以暴制暴 | ❌ **不行**，必须改剧情为合法路径 |
| 封建迷信成真 | ❌ **不行**，必须改科学闭环 |
| 未成年成人化 | ❌ **不行**，必须改人设 |
| 拜金炫富 / 婚恋对立 / 出轨洗白 | ❌ **不行**，必须改价值取向 |

> **判断法**：问「把它画成 Q 版，这件事本身还违规吗？」
> **画面违规 → Q 版能救；事情本身违规 → Q 版救不了，只会从"违规"变成"用可爱包装的违规"。**

## 8. 验收：什么算「对上了」

- [ ] 一眼是 **Q 版**（头身比约 1:2），不是写实比例
- [ ] 但**能认出是哪个角色**（发色、瞳色、服饰配色、标志性配饰与主线一致）
- [ ] 渲染路线与主线**同源**：不是 2D 平涂、不是日漫赛璐璐
- [ ] 画面内**没有任何文字**
- [ ] `[整活:风险]` 的镜头里**没有**血、伤口、刀具、武器
- [ ] 该镜**独立成单元**，未与主画风镜头混写
